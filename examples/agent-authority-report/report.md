### Beyond branch settings

Fix the findings above first: the guard does not replace branch rules, and it holds only where the agent's own credential cannot switch them off. Branch rules decide what may land on a branch. They treat every pull request the same, whoever wrote it, and they see nothing an agent does before it pushes. Haven's guard adds, for coding agents:

- one authority rule per agent: what it may merge itself, what needs a person's signed approval of that exact change, and what it may never touch;
- a check inside the agent's session (a Claude Code hook) that stops a protected action before it runs, including edits to its own rules or keys;
- a receipt for every decision, hash-chained so that an edited receipt is caught.

Shown so far with a live Claude Code agent in a sandbox, not yet on GitHub itself. How it works: https://github.com/charles-337/agent-authority-check#beyond-branch-settings
